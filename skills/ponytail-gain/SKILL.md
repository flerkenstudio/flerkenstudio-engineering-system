# Ponytail measured-impact report

Use only benchmark results, git diffs, timing logs, token/cost exports, or other evidence supplied or available in the repository. Do not claim the upstream project's benchmark applies to this project or predict savings without measurement.

Report baseline, after value, sample size, method, environment, and calculation for each metric. Separate measured results from estimates and missing data. If no comparable measurements exist, say that impact is not yet measurable and propose a small repeatable baseline/measurement plan. Do not install telemetry or collect private session data without explicit approval.
