# Ponytail help

Explain the local FAES integration and avoid claiming host features that are not available.

- `ponytail` — simplicity-first implementation mode; optional `lite`, `full`, `ultra`, `off` argument.
- `ponytail-review` — read-only review of a change with an extra simplicity pass; complements `code-review`.
- `ponytail-audit` — read-only whole-repository risk and complexity audit.
- `ponytail-debt` — inventory `shortcut:` / `ponytail:` limitation markers.
- `ponytail-gain` — measured impact report from actual data only.
- `karpathy-guidelines` — assumptions, simplicity, surgical edits, and goal-driven verification.

Antigravity Agent users can ask the agent to use a named skill or invoke it from the skill picker/slash interface if their installed Antigravity version exposes it. CLI users can install workspace/global skills with the supplied PowerShell scripts and invoke skills only where their CLI host supports Agent Skills. The shared `AGENTS.md` remains the always-on fallback. No CLI is required for the Agent workflow.
