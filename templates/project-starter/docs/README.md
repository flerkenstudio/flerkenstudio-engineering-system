# Project documentation

Create and maintain these documents as the product evolves:
- `PRD.md` — product scope and acceptance criteria
- `ARCHITECTURE.md` — system context, modules and data flows
- `DATABASE.md` — schema, constraints and migrations
- `API.md` — API/event contracts
- `SECURITY.md` — trust boundaries, controls and review notes
- `RUNBOOK.md` — deploy, monitor, backup, restore and incident procedures
