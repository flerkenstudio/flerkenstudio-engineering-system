# Gemini CLI Adapter (Tier 2)

Provides native compatibility with Google Gemini CLI.

- **Instruction File:** `GEMINI.md` at workspace root or `~/.gemini/GEMINI.md`.
- **Skill Discovery:** Placed in `.gemini/skills/` locally or `~/.gemini/skills/` globally.
- **Hooks:** Shell command integration in `.gemini/hooks.json`.
